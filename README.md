My entry for the make.fun bounty **Famous Last Words: The Funniest Epitaph**
($2): one tombstone line for a developer who finally caught his bug.

> Here lies a senior developer. He hunted one bug for ten years. Found it in
> the end: it was him. Status: won't fix.

## Run

```sh
python3 main.py
```

Writes the entry text (114 characters, no trailing newline) to
`/output/entry.txt`, creating the directory if needed.
